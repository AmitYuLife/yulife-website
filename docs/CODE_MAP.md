## 1. How to find a thing

Point at something on the page, then work down this list:

1. **Run the outline dump** in the browser to get the `data-src` name of the block:
   ```js
   [...document.querySelectorAll("[data-src]")].map(e=>e.dataset.src+(e.dataset.blockLabel?" — "+e.dataset.blockLabel:""))
   ```
2. **Look the name up** in §3 below to get `file:line`.
3. **Read only that range.** For files over 120 lines, §4 gives internal landmarks so you can offset straight to the right function.

If it is *copy* rather than layout, skip all of the above and go to the data file for that route (§2).
